# BUPT 智慧实景导航系统 (BuptGuide)

## 📌 项目简介

**BUPT 智慧实景导航系统** 是一款集成了地理信息展示、校园拓扑结构管理与经典图论算法演示的交互式软件[cite: 2]。

本项目以北京邮电大学（西土城校区）的真实建筑与道路布局为基础，建立了自定义逻辑坐标系（以“中门”为原点 $(0,0)$）[cite: 2]。系统不仅能够实现智能寻路、路径搜索与遍历，还支持用户自由进行校园拓扑结构的动态建构与拆除，并提供了直观的地图 UI 可视化交互[cite: 1, 2]。

---

## 🔥 核心功能

### 1. 智能路径规划 (最短路径)

* **算法实现**：基于 **Dijkstra（迪杰斯特拉）算法** 的变体[cite: 2]。
* **交互体验**：可通过**下拉框直接选择**或**输入关键字模糊搜索**起点与终点[cite: 2]。
* **视觉与日志反馈**：在地图上以 **红色粗实线** 高亮路径，同时在系统日志栏打印精确的路径节点序列及总米数[cite: 2]。

### 2. 校园图遍历演示

系统提供经典的图论搜索算法，演示计算机对校园拓扑网络的感知过程：

* **DFS（深度优先搜索）**[cite: 2]
* **BFS（广度优先搜索）**[cite: 2]
* **视觉反馈**：遍历轨迹统一显示为 **红色细虚线**[cite: 2]。

### 3. 动态道路与建筑管理

* **新建道路**：选择任意两个孤立节点，系统会自动根据坐标计算实际物理距离（以米为单位）并连线[cite: 1, 2]。
* **新建建筑**：支持在指定的逻辑坐标 $(x, y)$ 处放置新建筑节点[cite: 2]。
* **拆除管理**：输入建筑/节点名称即可销毁该节点及其关联的所有道路[cite: 2]。
* *注：系统内置防护机制，核心门户（如南门、中门、北门）被保护，禁止拆除[cite: 2]。*



### 4. 丰富的高级 UI 与地图交互

* **模糊搜索**：下拉选择框支持输入过滤（如输入“风味”自动匹配“风味餐厅”，输入“学”过滤宿舍）[cite: 1, 2]。
* **地图平移与缩放**：按住**鼠标右键拖拽**平移地图视口，滑动**鼠标滚轮**实现地图缩放[cite: 1, 2]。
* **动态比例尺与指北针**：集成可视化指北针，比例尺随滚轮缩放实时动态更新[cite: 1]。
* **实时日志系统**：系统界面配备实时文本窗口，即时反馈操作状态、错误提醒与算法计算序列[cite: 2]。

---

## 🛠️ 错误预防机制

* **名称查重**：新建建筑时若存在同名节点，系统将触发警告提醒[cite: 2]。
* **非法输入拦截**：坐标栏输入非数字等非法格式时，系统会自动拦截并提示“格式错误”[cite: 2]。
* **关键节点保护**：防止误删校园重要门户（南门、中门、北门等）[cite: 2]。

## 🎯 坐标系说明

* **参考原点 $(0,0)$**：以**中门**为坐标原点[cite: 2]。
* **距离单位**：逻辑坐标单位严格与实际校园实景比例挂钩（以中门到北门 500 米为校准基准）[cite: 1, 2]。
